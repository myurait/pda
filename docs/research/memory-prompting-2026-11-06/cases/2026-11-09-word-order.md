## 3. 整理

21:37 の発言に Claude Code が返した整理。用語の出典は一次資料で確かめていない。

### 3.1 用語

- 語順のかき混ぜ (scrambling): 日本語では、述語の前に置く「〜を」「〜で」「〜から」の順番を入れ替えても文法上は正しい。どの順にするかは別の原理で決まる。
- 情報構造: 文の中で、どれが既知の情報 (旧情報) で、どれが新しい情報 (新情報) かという区別。
- 旧から新へ (久野暲の「情報の流れの原則」): 既知の情報や話題を先に、新しい情報を後に並べるのが自然だとする原則。
- 焦点: その文が一番伝えたい新しい情報。日本語では述語の直前に置かれやすい。
- 長いものを先に (本多勝一『日本語の作文技術』の「長い修飾語ほど先に」): 長い句を先に出す傾向。
- 親和度 (同書の「親和度 (なじみ) の強弱」): 述語と結びつきの強い成分ほど述語の近くに置く。

### 3.2 例への当てはめ

| | 旧情報 (話題) | 新情報 (焦点) | Claude Code の語順 | 直した語順 |
|---|---|---|---|---|
| 例 1 | 報告の文の中身を | 作業の手順書やメモリにある語で | 新 → 旧 → 呼んだ | 旧 → 新 → 呼んだ |
| 例 2 | 2つの段落を | 字数の上限についてのご指摘に答えた私の応答から | 新 → 旧 → 書き直します | 旧 → 新 → 書き直します |

- どちらの例も、長い句を文頭に置き、その長い句が新情報だった。文が何についての話かを示す短い「〜を」は、述語の直前に置いていた。
- 読み手は、長い句が何についての話かを知らないまま読み進める。述語の直前には、伝えたい情報ではなく既知の語が来る。
- 例 1 は親和度にも反する。名前を表す成分 (「〜で呼ぶ」「〜と呼ぶ」の「〜」) は「呼ぶ」の直前に置くのが決まった形である。
- まとめ: 「長いものを先に」という長さの規則を、「旧から新へ」という情報の規則より優先して当てはめている。長さの規則は新情報どうしを並べるときに働くが、既知の話題と新情報が並ぶときは、長さに関係なく既知の話題が先に来る。
