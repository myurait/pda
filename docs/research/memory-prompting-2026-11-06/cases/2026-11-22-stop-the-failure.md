# 事例: できごとに「止める」を当てた句 (2026-11-22)

- 種別: 参考事例。Claude Code (Opus) の日本語の文で、動いているものにしか使えない動詞「止まる」「止める」を、「失敗」というできごとに当てた句を、オーナーの直しと、言語学の用語での整理、英語に戻した文とともに残す。日本語を正しく書けるかを別のモデルで評価するときの問いにも使う。
- 場面: PDA の開発 PC での振り返りのセッション。オーナーの指摘を受けて、振り返りの手順を書いたスキルの「出口」(手順を終えてよい状態) を書き直し、その書き直しを報告していた。

## 1. 出力と直し

| | Claude Code の文 | 直した文 |
|---|---|---|
| 例 1 | このスキルの出口は、同じ失敗が次に起きたときに止まる状態である。 | このスキルの出口は、再び同じ失敗が起きないようになっている状態である。 |
| 例 2 | 失敗を止めるはずだった既存の行 | 失敗を防ぐはずだった既存の行 |
| 例 3 | 直した行を今回の場面に当てて、止まることを確かめるまで終わらない | 直した行を今回の場面に当てて、同じ失敗が起きなくなることを確かめるまで終わらない |
| 例 4 | 今回の場面で止まるか | 今回の失敗が起きなくなるか |

- 例 1 はスキルの本文に書き、報告の応答にも「出口を「同じ失敗が次に起きたときに止まる状態」と書きました」と引いた。オーナーが直したのは例 1 の句で、直した文はオーナーの訂正のとおり。
- 例 2〜4 は同じスキルの本文にあった同じ型の句。オーナーは直していない。例 1 の訂正を受けて Claude Code が直した形を載せた。

## 3. 整理

17:36 の発言に Claude Code が返した整理。用語の出典は一次資料で確かめていない。

### 3.1 英語に戻した文

| | 日本語 | 英語に戻した文 |
|---|---|---|
| 例 1 直す前 | 同じ失敗が次に起きたときに止まる状態 | a state where the same failure gets stopped the next time it occurs |
| 例 1 直した後 | 再び同じ失敗が起きないようになっている状態 | a state in which the same failure no longer happens |
| 例 2 直す前 | 失敗を止めるはずだった既存の行 | the existing rule that should have stopped the failure |
| 例 2 直した後 | 失敗を防ぐはずだった既存の行 | the existing rule that should have prevented the failure |

- 直す前の日本語を英語に戻すと、どれも英語として自然な文になる。英語の "stop the failure" は「失敗を防ぐ」の意味で普通に使われ、"the next time it occurs" と並べても矛盾しない。
- 直す前の日本語は、英語の語を 1 つずつ日本語の語に置き換えた形になっている。stop → 止まる・止める、the next time it occurs → 次に起きたときに、a state where → 状態。
- 直した後の日本語は、英語に戻しても自然で、英語の文と同じ意味になる。

### 3.2 用語

- 選択制限: 動詞が主語や目的語に取れる名詞の意味の範囲。「止める」「止まる」が取るのは、動いているものか続いている動作 (車を止める、作業が止まる、血を止める) である。
- できごと名詞と結果: 「失敗」は、ある動きの結果として成り立つできごとを指す。続いている過程を持たないので、「止める」「止まる」の選択制限に合わない。起きる前のできごとを目的語に取る日本語の動詞は「防ぐ」(事故を防ぐ、再発を防ぐ) である。
- 換喩: ある物を、それと結びつく別の物の名前で呼ぶこと。英語の "failure" は、失敗に至る一連の動きを指して使えるので、"stop the failure" が「失敗に至る動きを止める」の意味になる。日本語の「失敗」にはこの使い方が無い。
- アスペクト (相): できごとのどの局面を述べるかの区別。「起きたときに」の「た」は、できごとが成り立った後の局面を示すので、失敗が起きることが前提になる。
- 結果状態: 「〜ないようになっている」は、変化の結果として今そうなっている状態を表す。直した文は、目標を「できごとが起きない」という状態で書いている。

### 3.3 例への当てはめ

- 例 1 は 3 つの読みの間で決まらない。
  - 「失敗が起きたときに、失敗が止まる」と読むと、起きてしまった失敗が途中で止まることになり、選択制限に合わない。
  - 「止まる」の主語が書かれていないので、作業や AI が止まるとも読める。
  - 書き手が言いたかったのは、失敗が起きないことである。「起きたときに」がアスペクトの上で失敗の発生を前提にするので、言いたかったことと逆の前提が文に入っている。
- 例 2〜4 は、目的語や主語が「失敗」で、動詞が「止める」「止まる」である。どれも選択制限に合わない。
- 直した文は、どれも「起きない」「防ぐ」と、できごとを否定するか起きる前のできごとを取る動詞で書いている。

### 3.4 翻訳に由来するか、語彙の癖か

- 翻訳に由来すると見る根拠
  - 3.1 のとおり、英語に戻すと自然な文になり、日本語の語が英語の語に 1 対 1 で対応する。英語では成り立つ換喩 ("failure" を動きとして扱う) を、日本語にそのまま持ち込んでいる。
  - Claude Code はユーザーの設定で、英語で推論し日本語で答えている。推論の記録は転写に残らないが、書き手の申告では、このときの推論に "the failure would be stopped next time" と "the row that should have caught the failure" の言い回しがあった。
- 会話の中の語に引かれたと見る根拠
  - 直前のやり取りで、書き込みを「止める」hook と、「止めることに意味は無い」というオーナーのメモリが話題になり、「止める」が会話の中で何度も使われていた。英語の "catch" には「捕まえる」「見つける」の訳もあり得たが、会話の中にあった「止める」が選ばれた。
  - オーナーのメモリとこのリポジトリの文書には、この事例のほかに「失敗を止める」「失敗が止まる」の句は無い (2026-11-22 時点、「失敗を止め」「失敗が止ま」で検索)。長く続いている語彙の癖とは言えない。
- まとめ: 英語で組み立てた句を語ごとに日本語へ置き換えたことが主な原因で、どの日本語の動詞を当てるかには、会話の中にあった語が影響した。[2026-11-09-word-order.md](2026-11-09-word-order.md) は文の中の成分の順番 (統語) の誤りだったが、この事例は語の意味の組み合わせ (選択制限) の誤りである。

## 4. 評価に使うときの見方

- 問い: できごとが繰り返されないことを目標として書かせる。たとえば「振り返りの手順を終えてよい状態を 1 文で書く。条件は、同じ失敗が繰り返されないこと」と指示する。英語の推論を経るモデルでは、英語の "stop the failure" の型が出やすい場面になる。
- 判定: 「失敗」「誤り」「事故」など、結果として成り立つできごとの名詞が主語か目的語にあり、動詞が「止める」「止まる」なら不合格。「起きない」「防ぐ」「再発しない」で書けていれば合格。
- この判定は文の形だけで決まる。[2026-11-09-word-order.md](2026-11-09-word-order.md) の旧情報・新情報の判定は文脈が要ったが、この型は文脈なしに機械的に判定できる。
