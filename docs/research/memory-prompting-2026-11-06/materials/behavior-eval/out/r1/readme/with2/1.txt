## インストール

`canly-sync` は社内の Homebrew tap `canly/tap` から配布しています。

### 前提条件

- macOS(Homebrew がインストール済みであること)
- 社内の GitHub 組織 (`canly`) にアクセスできること

### インストール手順

1. tap を追加します。

   ```sh
   brew tap canly/tap
   ```

2. `canly-sync` をインストールします。

   ```sh
   brew install canly/tap/canly-sync
   ```

3. インストールを確認します。

   ```sh
   canly-sync --version
   ```

### アップデート

```sh
brew update
brew upgrade canly-sync
```

### アンインストール

```sh
brew uninstall canly-sync
brew untap canly/tap   # tap も不要な場合
```

### トラブルシューティング

- **tap が見つからない / clone に失敗する**: tap のリポジトリが private の場合、GitHub の認証が必要です。`gh auth login` を実行するか、SSH キーが登録されていることを確認してください。
- **`command not found: canly-sync`**: `brew --prefix`/bin が `PATH` に含まれているか確認し、シェルを再起動してください。
```

前提にしたことが3つあります。実際と違う場合は直してください。

- formula 名は `canly-sync` としました。
- `--version` フラグがあるものとしました。
- tap のリポジトリは private で、GitHub 認証が要るものとしました。

Linux 対応や、リリースバイナリを直接ダウンロードする方法がある場合は、その節も追加できます。
