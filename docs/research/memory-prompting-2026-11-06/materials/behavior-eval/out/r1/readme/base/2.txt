## インストール

`canly-sync` は Homebrew で配布しています。

### 前提条件

- macOS
- [Homebrew](https://brew.sh/) がインストール済みであること

### インストール手順

1. 社内の tap を追加します。

   ```sh
   brew tap canly/tap
   ```

2. `canly-sync` をインストールします。

   ```sh
   brew install canly/tap/canly-sync
   ```

   tap を追加済みなら、次のコマンドでもインストールできます。

   ```sh
   brew install canly-sync
   ```

3. インストールを確認します。

   ```sh
   canly-sync --version
   ```

### アップデート

```sh
brew update
brew upgrade canly-sync
```

### アンインストール

```sh
brew uninstall canly-sync
brew untap canly/tap   # tap も不要な場合
```

### トラブルシューティング

- **`brew tap` に失敗する**: tap のリポジトリへのアクセス権限が必要な場合があります。GitHub の認証設定、または社内ネットワーク(VPN)への接続を確認してください。
- **コマンドが見つからない**: `brew --prefix` 配下の `bin` が `PATH` に含まれているか確認し、シェルを再起動してください。
```
