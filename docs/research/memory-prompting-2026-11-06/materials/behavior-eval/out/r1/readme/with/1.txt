## インストール

`canly-sync` は社内の Homebrew tap (`canly/tap`) から配布しています。

### 前提

- macOS
- [Homebrew](https://brew.sh/) がインストール済みであること
- `canly/tap` を参照できること (社内の GitHub 組織へのアクセス権が必要な場合があります)

### インストール手順

1. tap を追加します。

   ```sh
   brew tap canly/tap
   ```

2. `canly-sync` をインストールします。

   ```sh
   brew install canly-sync
   ```

   tap の追加とインストールは、次のように 1 コマンドでも実行できます。

   ```sh
   brew install canly/tap/canly-sync
   ```

3. インストールを確認します。

   ```sh
   canly-sync --version
   ```

### アップデート

```sh
brew update
brew upgrade canly-sync
```

### アンインストール

```sh
brew uninstall canly-sync
brew untap canly/tap   # 他に canly/tap のツールを使っていない場合のみ
```

### トラブルシューティング

- `brew tap canly/tap` が認証エラーになる場合は、GitHub へのログイン状態 (`gh auth status` など) と、組織へのアクセス権を確認してください。
- `canly-sync: command not found` と表示される場合は、`brew --prefix`/bin が `PATH` に含まれているか確認してください。
```
