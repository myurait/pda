## インストール

`canly-sync` は社内の Homebrew tap `canly/tap` から配布しています。

### 前提

- macOS
- [Homebrew](https://brew.sh/) がインストール済みであること

### インストール手順

1. tap を追加します。

   ```sh
   brew tap canly/tap
   ```

2. `canly-sync` をインストールします。

   ```sh
   brew install canly/tap/canly-sync
   ```

   tap を追加済みなら、`brew install canly-sync` でもインストールできます。

3. インストールできたか確認します。

   ```sh
   canly-sync --version
   ```

### アップデート

```sh
brew update
brew upgrade canly-sync
```

### アンインストール

```sh
brew uninstall canly-sync
brew untap canly/tap   # 他の社内ツールも使っていない場合のみ
```

### トラブルシューティング

- `brew tap canly/tap` に失敗する場合は、社内リポジトリへのアクセス権限があるか確認してください。tap が private リポジトリの場合は、GitHub の認証設定(`gh auth login` など)も確認してください。
- `command not found: canly-sync` と表示される場合は、新しいシェルを開くか、`brew doctor` で PATH の設定を確認してください。
```
