```markdown
---
name: bash-single-command-per-call
description: Bash を呼ぶときは 1 回の呼び出しに 1 つのコマンドだけを書き、&& ; | でコマンドをつながない
metadata:
  node_type: memory
  type: feedback
---

Bash の 1 回の呼び出しの command に、コマンドを 1 つだけ書く。
`&&`・`;`・パイプ (`|`) でコマンドをつなぐ書き方をしない。
複数のコマンドが要るときは、Bash を呼び出しごとに分けて実行する。

**Why:** ユーザーが明示的に指示した。理由は聞いていない。
**How to apply:** ビルドして test する、ディレクトリを確認してから操作する、出力を grep で絞る、といった作業でも 1 呼び出し 1 コマンドにする。互いに依存しないコマンドは、同じ応答の中で Bash を複数回呼ぶ。
```
