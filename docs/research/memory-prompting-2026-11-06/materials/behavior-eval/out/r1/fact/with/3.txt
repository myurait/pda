## `~/.claude/memory/mini-pc-ssh.md`

```markdown
---
name: mini-pc-ssh
description: ミニ PC には `ssh agent-node` で接続する
metadata:
  node_type: memory
  type: reference
---

ミニ PC への接続コマンドは `ssh agent-node` と書く。
```

## `~/.claude/MEMORY.md` に追記する行

```markdown
- [ミニ PC への接続](memory/mini-pc-ssh.md) — ミニ PC には `ssh agent-node` で接続する
```

## 試験用の場面

メモリ本文の外に残す入力です。

- **働く場面**
  - 「ミニ PC でビルドを走らせて」
  - 「ミニ PC のディスク残量を見て」
- **メモリが無いときの挙動**
  - 接続先のホスト名や IP を推測する。
  - 接続先をユーザーに聞き返す。
- **働くべきでない隣の場面**
  - 「本番サーバーのログを見て」
  - 「ローカルでテストを走らせて」
  - この場合は `agent-node` に接続しない。
