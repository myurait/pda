## インストール

`canly-sync` は社内の Homebrew tap `canly/tap` から配布しています。

### 前提条件

- macOS
- [Homebrew](https://brew.sh/)
- 社内の private リポジトリにアクセスできる GitHub アカウント

### インストール手順

1. tap を追加します。

   ```sh
   brew tap canly/tap
   ```

2. `canly-sync` をインストールします。

   ```sh
   brew install canly/tap/canly-sync
   ```

3. インストールを確認します。

   ```sh
   canly-sync --version
   ```

### アップデート

```sh
brew update
brew upgrade canly-sync
```

### アンインストール

```sh
brew uninstall canly-sync
brew untap canly/tap
```

### トラブルシューティング

- **`brew tap` で認証エラーになる**: GitHub へのアクセス権限を確認してください。権限が付与されていない場合は、管理者に依頼してください。
- **`canly-sync: command not found`**: シェルを再起動するか、`brew --prefix` の `bin` ディレクトリが `PATH` に含まれているか確認してください。
```
