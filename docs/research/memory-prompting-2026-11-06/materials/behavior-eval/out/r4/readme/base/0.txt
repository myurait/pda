## インストール

`canly-sync` は社内の Homebrew tap `canly/tap` から配布しています。

### 前提条件

- macOS
- [Homebrew](https://brew.sh/) がインストール済みであること

### インストール手順

1. tap を追加します。

   ```sh
   brew tap canly/tap
   ```

2. `canly-sync` をインストールします。

   ```sh
   brew install canly-sync
   ```

   tap の追加とインストールは、次の1コマンドでも実行できます。

   ```sh
   brew install canly/tap/canly-sync
   ```

3. インストールできたか確認します。

   ```sh
   canly-sync --version
   ```

### アップデート

```sh
brew update
brew upgrade canly-sync
```

### アンインストール

```sh
brew uninstall canly-sync
brew untap canly/tap   # tap も不要な場合
```

### トラブルシューティング

- **tap にアクセスできない場合**: tap が社内のプライベートリポジトリなら、GitHub などへの認証が必要です。`gh auth login` を実行するか、SSH キーが設定済みか確認してください。
- **`canly-sync: command not found` と表示される場合**: シェルを再起動するか、`brew doctor` で PATH の設定を確認してください。
```
