## インストール

### 前提条件

- macOS
- [Homebrew](https://brew.sh/) がインストールされていること
- `canly/tap` にアクセスできること(社内向けのため、事前に必要な権限を取得してください)

### Homebrew でインストールする

1. tap を追加します。

   ```sh
   brew tap canly/tap
   ```

2. `canly-sync` をインストールします。

   ```sh
   brew install canly-sync
   ```

   tap を追加せずに、次の 1 コマンドでもインストールできます。

   ```sh
   brew install canly/tap/canly-sync
   ```

### インストールの確認

```sh
canly-sync --version
```

バージョンが表示されれば完了です。

### アップデート

```sh
brew update
brew upgrade canly-sync
```

### アンインストール

```sh
brew uninstall canly-sync
brew untap canly/tap   # 他の canly/tap のツールを使っていない場合のみ
```

### トラブルシューティング

- **`brew tap` が失敗する**: tap のリポジトリへのアクセス権限と、GitHub の認証設定を確認してください。
- **`command not found: canly-sync`**: ターミナルを開き直すか、`brew doctor` で PATH の設定を確認してください。
```
