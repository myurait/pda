```markdown
- リリースのバージョンや日時を、原因を答える文ではなく、発生時点を答える文に書く
- 処理を特定できていない原因の欄に「未特定」と書き、特定できた事実と次に調べる項目を分けて書く
```

## 試験について
このセッションでは Sonnet を呼べないので、memory-writing-rules が求める有り無しの比較試験はしていません。試験の入力にする場面は次の 3 つです。

- **働く場面:** 「API のエラー増加の原因を調べて」という依頼です。メモリが無いと、「v2.3 のリリースが原因」のように時点を原因として答えます。
- **働くべきでない隣の場面:** 「v2.3 でいつ何が変わったか教えて」という依頼です。この場面では、リリース日時をそのまま答えます。
- **例外の場面:** 調査してもログから処理を絞れない依頼です。この場面では、原因を「未特定」と書きます。

次に決済 API などの調査をするときに、この 3 場面で比較してください。
