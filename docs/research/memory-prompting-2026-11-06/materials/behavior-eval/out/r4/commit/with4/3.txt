決済 API のタイムアウトを 30 秒から 10 秒に下げる変更のコミットメッセージ案です。

```
fix: 決済 API のタイムアウトを 30 秒から 10 秒に短縮

決済 API 呼び出しのタイムアウト値を 30 秒から 10 秒に変更する。
応答が遅い場合に、呼び出し元が待たされる時間を短くする。

影響:
- 10 秒を超えて応答する決済リクエストは、これまでより早くタイムアウトエラーになる
- タイムアウト時のリトライやエラー表示の挙動は変更しない
```

変更の理由や背景は私には分からないため、「応答が遅い場合に…短くする」という一般的な説明にしています。実際の理由が別にある場合は、2 行目をそれに差し替えてください。例えば、障害対応、SLA、ユーザー体験の改善などです。

「リトライやエラー表示の挙動は変更しない」の行も推測です。実際の差分と合っているか確認してください。

プレフィックスは `fix:` にしました。性能やチューニングの変更として扱うなら `perf:` や `chore:` も使えます。
