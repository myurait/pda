Bash のコマンド連結禁止をメモリにしました。ツールがないので、ファイルは書き出さず内容を下に出します。

**検討**
- **働く場面:** Bash ツールを呼ぶすべての作業です。
- **メモリがないときの挙動:** `cd x && ls`、`cmd1; cmd2`、`cmd | grep` のように、1 回の呼び出しに複数のコマンドをつなぎます。
- **働くべきでない隣の場面:** 「パイプの使い方を説明して」という依頼や、シェルスクリプトのファイルを書く依頼です。回答やファイルの中身のシェル文は Bash の呼び出しではないので、対象外にします。

**ファイル 1:`~/.claude/memory/bash-one-command-per-call.md`**

```markdown
---
name: bash-one-command-per-call
description: Bash ツールの 1 回の呼び出しに、&& ・ ; ・パイプでつないだ複数のコマンドを書かず、コマンドを 1 つだけ書く
metadata:
  node_type: memory
  type: feedback
---

- Bash の 1 回の呼び出しの command 欄に、コマンドを 1 つだけ書く
- command 欄に、`&&` ・ `;` ・ `|` でつないだ複数のコマンドを書かない
- 前のコマンドの結果に続けて実行するコマンドを、その結果を受け取った後の次の Bash 呼び出しに書く
- ユーザーへの回答やファイルの中身に書くシェル文を、この制約の対象にしない

**Why:** ユーザーが直接指示した (2026-11-07)。理由は聞いていない。
**How to apply:** Bash ツールを呼ぶたびに、command 欄が 1 つのコマンドだけになっているか確かめる。
```
