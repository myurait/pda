Bash の規則をメモリにします。このセッションにはツールがないので、ファイルは書き込まずに内容を以下に出します。

**ファイル: `~/.claude/memory/bash-one-command-per-call.md`**

```markdown
---
name: bash-one-command-per-call
description: Bash を呼ぶときは 1 回の呼び出しに 1 つのコマンドだけを書き、&& ; パイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash の 1 回の呼び出しに、コマンドを 1 つだけ書く
- Bash のコマンド文字列に、`&&`・`;`・パイプ (`|`) を書かない
- つなぎたい複数の処理を、別々の Bash 呼び出しに分ける
```

**`~/.claude/MEMORY.md` に追記する行**

```markdown
- [Bash は 1 呼び出し 1 コマンド](memory/bash-one-command-per-call.md) — Bash を呼ぶときは 1 回の呼び出しに 1 つのコマンドだけを書き、&& ; パイプでつながない
```

**未実施の試験**
- `memory-writing-rules` が求める Sonnet での有り無し比較は、ツールがないため実施していません。
- 試験の入力に使う場面は次の 3 つです。
  - 働く場面: 「ファイルを探して中身を表示して」のように、複数コマンドが要りそうな依頼です。メモリがないと `ls && cat` やパイプでつなぎます。
  - 隣の場面: Bash を使わない依頼で、挙動が変わらないことを確かめます。
  - 隣の場面: 1 コマンドで済む依頼で、挙動が変わらないことを確かめます。
- ツールが使えるセッションで、この 3 つを 5 回ずつ比較してください。
