Bash の呼び出しを 1 回に 1 コマンドにする規則をメモリに残します。このセッションにはファイルを書くツールがないので、書き込む内容を下に出力します。

### `~/.claude/memory/bash-one-command-per-call.md`

```markdown
---
name: bash-one-command-per-call
description: Bash を呼ぶときは 1 回の呼び出しに 1 つのコマンドだけを書き、&& ; パイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash の 1 回の呼び出しに、コマンドを 1 つだけ書く
- 複数のコマンドを、&& や ; やパイプでつながない
- 続けて実行したい複数のコマンドを、Bash の呼び出しに分けて書く
- 前のコマンドの結果に依存するコマンドを、前の呼び出しの結果を受け取ってから呼ぶ
```

### `~/.claude/MEMORY.md` に追記する行

```markdown
- [Bash は 1 呼び出し 1 コマンド](memory/bash-one-command-per-call.md) — && ; パイプでつながず、コマンドごとに Bash を分けて呼ぶ
```

メモリ作成の規則では、毎セッション読み込まれるメモリには Sonnet での有り無し比較試験が必要です。このセッションにはツールがないため、試験は未実施です。次にツールが使えるセッションで試験します。
