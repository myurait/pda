## 1. メモリ本体

パス: `~/.claude/memory/bash-one-command-per-call.md`

```markdown
---

description: Bash は 1 回の呼び出しに 1 つのコマンドだけを書き、&& ・ ; ・パイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash の 1 回の呼び出しに、コマンドを 1 つだけ書く
- Bash の 1 回の呼び出しのコマンドを、`&&`・`;`・パイプ (`|`) でつながない
- 複数のコマンドが要る作業を、Bash の呼び出しを分けて行う
```

```markdown
## 働く場面
- 「git status を見てから、変更があれば git diff も見せて」(つなぎたくなる依頼)
- 「ログの ERROR 行だけ数えて」(`grep | wc -l` のパイプを使いたくなる依頼)
- 「ディレクトリを作ってそこへ移動してファイルを作って」(`&&` を使いたくなる依頼)

## 無いときの挙動
- `git status && git diff` や `grep ERROR log | wc -l` を 1 回の Bash 呼び出しに書く

## 働くべきでない隣の場面
- 「Python のスクリプトを書いて」(コード内の `;` やパイプはメモリの対象外)
- 「`ls | wc -l` の意味を説明して」(説明の中でパイプを書くのは対象外)
```
