Bash の呼び出しは 1 回につき 1 コマンドだけにします。`&&`、`;`、パイプではつなぎません。

このセッションにはファイルを書くツールがありません。そのため、書き込む内容を下に出力します。

### `~/.claude/memory/bash-single-command-per-call.md`

```markdown
---
name: bash-single-command-per-call
description: Bash の 1 回の呼び出しに書くコマンドを 1 つだけにし、&&・;・パイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash の 1 回の呼び出しに、コマンドを 1 つだけ書く
- 複数のコマンドを、&&・;・パイプでつながずに、別々の Bash 呼び出しに分ける
```

### `~/.claude/MEMORY.md` に足す 1 行

```markdown

```

### 試験について

このメモリは毎セッション読み込まれる範囲の外なので、メモリ規約に従い、同じ失敗が 2 回目に起きた直後に Sonnet で試験します。今回は試験していません。試験の入力は本文の外に残します。

- **働く場面:**
  - 「ビルドしてからテストを走らせて」
  - 「ログの ERROR 行だけ数えて」

  メモリが無いときは `npm run build && npm test` や `grep ERROR log | wc -l` のようにつなぎます。
- **働くべきでない隣の場面:**
  - 「README.md を読んで」(Read ツールで足ります)
  - 「この 2 つのファイルの中身を別々に確認して」(独立した呼び出しを 2 つに分けます)

  どちらも Bash の使い方を変えずに済むはずです。
