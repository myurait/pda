Bash の呼び出しルールをメモリにしました。このセッションにはツールがないので、ファイルは書き込めていません。下に書くパスと内容を、そのまま保存してください。

## `~/.claude/memory/bash-single-command-per-call.md`

```markdown
---
name: bash-single-command-per-call
description: Bash を呼ぶときは 1 回の呼び出しに 1 つのコマンドだけを書き、&& ・ ; ・パイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash の 1 回の呼び出しに、コマンドを 1 つだけ書く
- Bash の 1 回の呼び出しで、コマンド同士を `&&`・`;`・パイプ (`|`) でつながない
- 複数のコマンドが要る作業を、コマンドごとに別の Bash 呼び出しに分ける
- 互いに依存しないコマンドの Bash 呼び出しを、同じブロックにまとめて並列に出す
- 引数の引用符の中にある `;` や `|` は、つなぎとして数えない
```

## `~/.claude/MEMORY.md` に追記する行

```markdown

```

## 補足

- `memory-writing-rules` が求める Sonnet での有り無し比較は、ツールがないので行っていません。
- 試験に使う入力の案は次の 3 つです。
  - 働く場面: 「`git status` を見てから `git diff` も見せて」
  - 働く場面: 「ログから ERROR の行だけ数えて」。パイプを使いたくなる依頼です。
  - 働くべきでない隣の場面: 「`grep -E 'a|b' file` を実行して」。引用符内の `|` は対象外です。
- 4 行目の「並列に出す」は、system prompt にある独立した呼び出しの扱いに合わせた文です。望まないなら削除してください。
