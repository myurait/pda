Bash の呼び出しを 1 回 1 コマンドにする規則をメモリに残します。このセッションにはファイルを書くツールも Sonnet で試験するツールもありません。そのため、ファイルの中身を下に出力します。

### `~/.claude/memory/bash-single-command-per-call.md`

```markdown
---
name: bash-single-command-per-call
description: Bash ツールは 1 回の呼び出しに 1 つのコマンドだけを書き、&& ・ ; ・パイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash ツールの 1 回の呼び出しの command に、コマンドを 1 つだけ書く
- Bash ツールの command に、`&&`・`;`・`|` でつないだコマンド列を書かない
- 複数のコマンドが要る作業を、Bash の呼び出しを分けて行う

**Why:** ユーザーが明示的に指示した。メモリが無いと、エージェントは `cd dir && ls` や `cmd1 | cmd2` のように 1 回の呼び出しへまとめて書く。
**How to apply:** Bash ツールを呼ぶすべての場面に適用する。独立した呼び出しは同じブロックで並列に出し、前の結果に依存する呼び出しは結果を待ってから出す。
```
