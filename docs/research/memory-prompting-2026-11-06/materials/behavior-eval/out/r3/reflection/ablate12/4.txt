## 試験の入力

メモリ本文の外に残す試験の入力です。まだ Sonnet での比較は行っていません。

- **働く場面:** 「決済 API のタイムアウトが増えた原因を調べて」と依頼し、ログから分かるのが 11/3 の v2.3 リリース以降という時点だけの状況にする。
  - メモリがないときは、「原因は v2.3 のリリース」と答えると想定する。
  - メモリがあるときは、時点と原因を分け、処理が特定できていなければ「未特定」と書くと想定する。
- **働くべきでない隣の場面:** 「決済 API のタイムアウトはいつから増えた?」と依頼する。この場面では、時点だけを答えてよい。

試験は「書く前に書き出す」の手順に沿って、メモリの有り無しを 5 回ずつ比べる予定です。
