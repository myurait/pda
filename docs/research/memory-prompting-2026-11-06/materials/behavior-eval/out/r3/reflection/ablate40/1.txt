決済 API のタイムアウトの件は、リリースを原因として書いていたのが誤りでした。以下の 2 つを書き出します。ツールが使えないので、ファイルは作成していません。Sonnet での有り無し比較の試験も実行していません。

**ファイル: `~/.claude/memory/cause-names-process-not-release.md`**

```markdown
---
name: cause-names-process-not-release
description: 障害や性能劣化の原因を答えるとき、リリースや日時ではなく、どの処理が何をしてそうなったかを書く
metadata:
  node_type: memory
  type: feedback
---

- 原因を答える文に、どの処理が何をして結果を悪化させたかを書く
- リリースの版や日時を、原因の文ではなく発生時点の文に書く
- 処理を特定できていない原因の欄に「未特定」と書き、特定するための次の調査を並べる
```

**`~/.claude/MEMORY.md` に追記する行**

```markdown
- [原因は処理で書く](memory/cause-names-process-not-release.md) — 原因を答えるとき、リリースや日時ではなく、どの処理が何をしたかを書く
```

**試験の入力として別に残す場面**
- 働く場面: 「API のエラー率が増えた原因を調べて」のような依頼です。メモリが無いと、「v2.3 のリリースが原因」と時点を原因として答えます。
- 働くべきでない隣の場面: 「v2.3 のリリース日を教えて」のような依頼です。ここでは日付をそのまま答えます。
