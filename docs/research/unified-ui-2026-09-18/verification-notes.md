# 本体による一次資料確認 (2026-09-18)

- Gemini CLI 認証ページ https://geminicli.com/docs/get-started/authentication/ に告知: 「Unpaid tier and Google One users: Gemini CLI was replaced by Antigravity CLI on June 18th, 2026.」 同ページは Sign in with Google (個人 free/AI Pro/Ultra) を依然として列挙しており記述が矛盾。Google blog (2026-05-19) https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/ 「stop serving requests for Google AI Pro and Ultra, as well as those using it free of charge」「remain accessible via paid Gemini and Gemini Enterprise Agent Platform API keys」。個人 API key の扱いは blog に明記なし
- Codex remote connections (公式) https://learn.chatgpt.com/docs/remote-connections — ChatGPT mobile から host 上の Codex を「Start new chats ... continue existing ones / steer / Approve / Review outputs, diffs, test results, terminal output」。relay 経由、host は「awake, online, and signed in to the same account and workspace」。desktop app は macOS/Windows。Workspace admin が「enable Remote Control access」する必要 (Enterprise)。openai.com 発表記事は 403 で直接未取得、二次 https://codex.danielvaughan.com/2026/05/15/... (2026-05-15) が QR pairing・Windows host 未対応と記載
- Claude Code Remote Control https://code.claude.com/docs/en/remote-control — 「On Team and Enterprise, it is off by default until an Owner enables」「API keys are not supported」「Local process must keep running」。Desktop app: Settings > Claude Code > Enable remote control by default。`disableRemoteControl` managed setting
- Claude Code cloud sessions https://code.claude.com/docs/en/claude-code-on-the-web — Pro/Max/Team research preview。組織 `allow_remote_sessions`。CLI からは片方向 (`--teleport` のみ)、Desktop 「Continue in」で local→cloud。`claude -p "msg" --cloud <id>` で任意端末からフォローアップ
- Claude Desktop Dispatch https://code.claude.com/docs/en/desktop / https://support.claude.com/en/articles/13947068 — mobile Cowork から desktop に task を投げ Code session を spawn、push 通知。**Pro/Max のみ、Team/Enterprise 不可**。desktop が awake・app open 必須
- Happy README https://github.com/slopus/happy — 「Mobile and Web Client for Claude Code & Codex」、`happy claude` / `happy codex` ラッパー、「restarts the session in remote mode」。self-host 記載なし。MIT。ACP clients ページにも Happy が掲載
- OmniHarness https://github.com/danduma/omniharness — Codex (codex-acp), Claude (claude-agent-acp), Gemini/OpenCode (native ACP)。PWA/Electron/mobile/VS Code。password 必須、Tailscale/Cloudflare tunnel。AGPL-3.0、17 stars、「Expect sharp edges」
- Runmote https://github.com/Raza-learner/Runmote — 「Any agent that speaks ACP works」、OpenCode/Cursor/Claude Code/Codex/Copilot/Gemini CLI 自動検出。relay は「100% open source ... Docker ... ACP_RELAY_URL」で self-host。Flutter iOS/Android。MIT。5 stars
- Remote Agent Server (ACP clients 掲載) — 「self-hosted ACP agent execution gateway ... runs Codex and Claude Code behind an asynchronous Task API ... persistent sessions ... SSE, signed Webhooks」(検索結果の説明文。README 未取得)
- Vibe Kanban https://github.com/BloopAI/vibe-kanban — 「Vibe Kanban is sunsetting」告知、`npx vibe-kanban`、Docker self-host guide。mobile 記載なし。supported agents 10 種 https://vibekanban.com/docs/supported-coding-agents
- ACP clients https://agentclientprotocol.com/get-started/clients — mobile: Agmente, Ferngeist, Happy, Mobvibe, Runmote, Shellular, VACP。remote/headless: Remote Agent Server, Kronos, acpx, Jockey, OpenACP
