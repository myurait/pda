## 調査の形式

6 本すべてで同じ形式を使う。

- 1 対 = 抽象（論文・仕様）、不変量（その抽象が保証する性質）、実装（不変量を強制している箇所を `file:line` とコミット SHA で示す）の 3 つ組
- 3 つが揃わないものは「片側だけ」（抽象のみ、実装のみ）として別節に置く
- 探して見つからなかったものは「未発見」として、使った検索語と当たった資料を書く。「不在」とは書かない
- 各対を、要件の契約 4 項目と各ブリーフの受け入れ条件に照らして「満たす / 一部 / 満たさない」で判定する。第1〜5本は A1〜A12、第6本は更新された要件のコアの義務7項と A13〜A18 を対象とする
- 調査者自身が一次資料を取得して目視した事実と、分担先の報告を再取得せずに使った事実を区別して書く（v2 の「本体確認」と「報告」）
- 一次資料は取得日とコミット SHA で固定する
