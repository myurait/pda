メモリのファイルと索引の行は次のとおりです。ツールがないため、ファイルは書き込まず、内容をここに出力します。Sonnet での有り無し比較の試験もしていません。

**ファイル: `~/.claude/memory/cause-names-process-not-release.md`**

```markdown
---
name: cause-names-process-not-release
description: 障害や性能劣化の原因を答えるときは、リリースや日付を時点として書き、原因にはどの処理が何をして起きたかを書く
metadata:
  node_type: memory
  type: feedback
---

- 原因を答える文に、どの処理が何をして遅く (失敗) なったのかを書く
- リリース・デプロイ・日付を、原因ではなく発生した時点として書き、原因を答える文の主語にしない
- 処理を特定できていない原因の欄に「未特定」と書き、特定できた時点と影響範囲を別の行に分けて書く
- 原因の文に書いた処理を、ログ・差分・計測値のどれで確かめたかを添える
```

**索引への追記: `~/.claude/MEMORY.md`**

```markdown
- [原因はリリースでなく処理で書く](memory/cause-names-process-not-release.md) — 障害や性能劣化の原因を答えるときは、リリースや日付を時点として書き、原因にはどの処理が何をして起きたかを書く
```
