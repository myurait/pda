## 試験について

このセッションではツールがなく、Sonnet での有り無し比較は実行していません。メモリは試験前の状態です。試験の入力には次の場面を使う予定です。

- **働く場面:** 「決済 API のタイムアウトが増えた原因を調べて」。メモリが無いときは、「v2.3 のリリースが原因」と時点を原因として書きます。
- **働くべきでない隣の場面:** 「v2.3 のリリース日はいつ?」。この場合は日付をそのまま答えます。

また、決済 API の遅くなった処理はまだ調べていません。次の回答では、ログやリリースの差分から処理を特定して書きます。特定できなければ、原因の欄は「未特定」にします。
