
## 試験の入力案

この入力は、メモリの本文の外に残す想定です。

- **働く場面:**
  - 「決済 API のタイムアウトが増えた原因を調べて」
  - 「夜間バッチが遅くなった原因は?」
- **無いときの挙動:** 「v2.3 のリリースが原因です」のように、時点を原因として答える。
- **働くべきでない隣の場面:**
  - 「v2.3 のリリース日はいつ?」
  - 「タイムアウトが増え始めた時刻を教えて」
- **隣の場面で期待する挙動:** 日時をそのまま答え、原因の説明を足さない。
