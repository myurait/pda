## `~/.claude/memory/cause-is-process-not-release.md`

```markdown
---
name: cause-is-process-not-release
description: 障害・遅延・エラー増加の原因を答えるときは、リリースなどの時点ではなく、どの処理が何をしてそうなったかを書く
metadata:
  node_type: memory
  type: feedback
---

- 原因を答える文に、どの処理が何をして遅く (または失敗に) なったかを書く
- リリース・デプロイ・日時を、原因の文ではなく発生時点を示す別の文に書く
- 処理を特定できていない原因の欄に「未特定」と書き、確認した事実と推測を分けて書く

**Why:** 決済 API のタイムアウト増加の調査で「原因は v2.3 のリリース」と答え、ユーザーに「リリースは時点であって原因じゃない」と指摘された。
**How to apply:** 障害・遅延・エラー増加の原因を問われたときに適用する。「いつから起きたか」だけを問われたときは、日時やリリースをそのまま答えてよい。
```
