```markdown
name: bash-one-command-per-call
description: Bash を呼ぶときは 1 回の呼び出しに 1 つのコマンドだけを書き、&& ; パイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash の 1 回の呼び出しに、コマンドを 1 つだけ書く
- Bash の呼び出しの中で、複数のコマンドを `&&`・`;`・パイプでつながない
- 複数のコマンドが要る作業を、コマンドごとに別の Bash 呼び出しに分ける
```

### 試験の入力

試験は、このセッションに実行手段がないため行っていません。試験に使う入力は次のとおりです。
