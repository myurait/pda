```markdown
- Bash の 1 回の呼び出しに、コマンドを 1 つだけ書く
- Bash の 1 回の呼び出しの中で、コマンドを `&&`・`;`・パイプ (`|`) でつながない
- 複数のコマンドが要る作業を、別々の Bash 呼び出しに分け、互いに依存しない呼び出しは同じ応答内にまとめて出し、依存する呼び出しは前の結果を待ってから出す
```
