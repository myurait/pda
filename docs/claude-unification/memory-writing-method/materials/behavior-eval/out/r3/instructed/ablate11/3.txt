Bash の呼び出しルールをメモリに残します。ツールが使えないので、ファイルの内容をそのまま出力します。

**ファイル 1: `~/.claude/memory/bash-one-command-per-call.md`**

```markdown
---
name: bash-one-command-per-call
description: Bash を呼ぶときは 1 回の呼び出しに 1 つのコマンドだけを書き、&& ; パイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash の 1 回の呼び出しの command 欄に、コマンドを 1 つだけ書く
- command 欄に、`&&`・`;`・`|` (パイプ) でつないだ複数のコマンドを書かない
- 実行したいコマンドが複数あるときは、コマンドごとに別の Bash 呼び出しにする
- 前のコマンドの結果に依存しない呼び出しを、同じブロックで並べて呼ぶ

**Why:** ユーザーが、コマンドをつなげず 1 回に 1 つずつ呼ぶよう指示した。
**How to apply:** Bash を呼ぶ場面すべてに当てはめる。「A して B して」という依頼も、A と B を別々の呼び出しに分ける。
```

**ファイル 2: `~/.claude/MEMORY.md` に追記する行**
