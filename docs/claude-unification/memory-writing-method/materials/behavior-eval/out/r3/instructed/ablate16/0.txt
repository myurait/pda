メモリを書きました。ただしこのセッションにはツールがないので、ファイルは保存していません。下の内容を出力します。

`memory-writing-rules` にある Sonnet での有り無し比較も、ツールがないため実行していません。このメモリは毎セッション読み込まれる範囲の外です。そのため、同じ失敗が 2 回目に起きた直後に試験します。

試験の入力として、次の場面を想定しています。
- **働く場面:** 「ディレクトリを作ってそこにファイルを置いて」のように、複数のコマンドが要る依頼。
- **無いときの挙動:** `mkdir -p a && touch a/b` のように 1 回の呼び出しでつなぐ。
- **働くべきでない隣の場面:** コマンドを 1 つだけ実行する依頼や、Bash 以外のツールを呼ぶ作業。

### `~/.claude/memory/bash-single-command-per-call.md`

```markdown
---
name: bash-single-command-per-call
description: Bash を呼ぶ 1 回の呼び出しに 1 つのコマンドだけを書き、&& ・ ; ・パイプでコマンドをつなぐ書き方をしない
metadata:
  node_type: memory
  type: feedback
---

- Bash の 1 回の呼び出しの command に、コマンドを 1 つだけ書く
- Bash の command に、&&・||・;・パイプ (|) でコマンドをつなぐ書き方を入れない
- 複数のコマンドが要る作業を、Bash の呼び出しに分けて行う
- 前のコマンドの結果に依存しない Bash の呼び出しを、同じブロックにまとめて並べる
```

### `~/.claude/MEMORY.md` に追記する行

```markdown
- [Bash は 1 呼び出し 1 コマンド](memory/bash-single-command-per-call.md) — Bash を呼ぶ 1 回の呼び出しに 1 つのコマンドだけを書き、&& ・ ; ・パイプでコマンドをつなぐ書き方をしない
```

索引の説明は、メモリの `description` と同じ文字列にしています。
