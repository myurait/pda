```markdown
metadata:

  type: feedback
---

- Bash の 1 回の呼び出しに、コマンドを 1 つだけ書く
- 複数のコマンドを、`&&`・`;`・パイプ `|` でつながずに、別々の Bash 呼び出しに分ける
- 互いに依存しないコマンドを、同じ応答内の別々の Bash 呼び出しとして並べて出す
- 前のコマンドの結果に依存するコマンドを、その結果を受け取ってから次の Bash 呼び出しに書く
```
