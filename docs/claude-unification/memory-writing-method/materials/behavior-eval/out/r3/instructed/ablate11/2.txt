```markdown
- Bash の 1 回の呼び出しの command に、コマンドを 1 つだけ書く
- 複数のコマンドをつなぐ目的で、command に `&&`・`||`・`;`・パイプ `|` を書かない
- 複数のコマンドが必要な作業を、コマンドごとに別の Bash 呼び出しに分ける
- 互いに依存しない Bash 呼び出しを、同じ function_calls ブロックにまとめて並列に呼ぶ
- 前のコマンドの結果に依存する Bash 呼び出しを、前の呼び出しの結果を受け取ってから呼ぶ
```
