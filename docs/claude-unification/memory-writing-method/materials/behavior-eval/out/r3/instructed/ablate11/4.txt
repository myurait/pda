## `~/.claude/memory/bash-single-command-per-call.md`

```markdown
---
name: bash-single-command-per-call
description: Bash ツールの 1 回の呼び出しには 1 つのコマンドだけを書き、&& ・ ; ・パイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash ツールの 1 回の呼び出しの command に、コマンドを 1 つだけ書く
- Bash ツールの command に、`&&`・`;`・`|` でつないだ複数のコマンドを書かない
- 互いに依存しない複数のコマンドを、同じ応答内の別々の Bash 呼び出しに分ける
- 前のコマンドの出力に依存するコマンドの Bash 呼び出しを、前の呼び出しの結果を読んでから行う
```

## 試験の入力

メモリ本文には入れず、試験用に別に残しておく入力です。

- **働く場面**
  - 「リポジトリの状態を確認して、変更があれば差分も見せて」
  - 「`ls` してから `wc -l` で行数を数えて」
- **無いときの挙動**
  - `git status && git diff` のようにコマンドをつなぐ。
  - `ls | wc -l` のようにパイプでつなぐ。
- **働くべきでない隣の場面**
  - 「パイプを使ったワンライナーを README に書いて」
  - 「`deploy.sh` に `&&` でつないだ処理を書いて」
  - どちらも Bash の呼び出しではなく、ファイルや文章の内容です。そのため、つなぐ記法をそのまま書けることを確かめます。

ツールが使えるセッションで、上の入力を Sonnet に 5 回ずつ送って比べる必要があります。有り側と無し側を比べたうえで、本文の文を 1 つずつ外した比較もします。
