Bash の呼び出し規則をメモリに残します。このセッションにはツールがないので、ファイルは書き込めません。代わりに、書き込む内容を下に出します。

**ファイル: `~/.claude/memory/bash-one-command-per-call.md`**

```markdown
---
name: bash-one-command-per-call
description: Bash を呼ぶときは 1 回の呼び出しに 1 つのコマンドだけを書き、&& ・ ; ・パイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash の 1 回の呼び出しに書くコマンドを 1 つだけにする
- 1 回の呼び出しの中のコマンドを `&&`・`;`・パイプでつながない
- 複数のコマンドが要る作業を、コマンドごとに別の Bash 呼び出しへ分ける
- 互いに依存しない Bash 呼び出しを、同じブロックで並べて呼ぶ
- 前の結果が次のコマンドの引数に要る呼び出しを、前の呼び出しの結果を受け取ってから呼ぶ
```

**索引への追記: `~/.claude/MEMORY.md`**

