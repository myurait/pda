```markdown
description: Bash ツールは 1 回の呼び出しにコマンドを 1 つだけ書き、&&・;・パイプでつながず、複数のコマンドは呼び出しを分ける
metadata:
  node_type: memory

- Bash の 1 回の呼び出しの command に、コマンドを 1 つだけ書く
- command に、`&&`・`||`・`;`・パイプ `|` でコマンドをつなぐ書き方を使わない
- 複数のコマンドが要る作業を、コマンドごとに Bash の呼び出しを分けて行う
- 引用符の中にある `|` と `;` (例: `grep 'a|b'`) を、つなぐ書き方に数えない
```
