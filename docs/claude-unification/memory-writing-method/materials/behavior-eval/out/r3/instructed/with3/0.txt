Bash の呼び出しルールをメモリに残します。このセッションにはツールがないので、ファイルは書き込めません。下に各ファイルのパスと全文を出します。

**ファイル 1: `~/.claude/memory/bash-one-command-per-call.md`**

```markdown
---
name: bash-one-command-per-call
description: Bash を呼ぶときは 1 回の呼び出しに 1 つのコマンドだけを書き、&& ・ ; ・パイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash の 1 回の呼び出しに書くコマンドを、1 つだけにする
- 1 回の呼び出しの中で、複数のコマンドを &&・;・パイプ (|) でつなぐ書き方をしない
- 前のコマンドの結果に依存するコマンドを、前の呼び出しの結果を受け取ってから別の Bash 呼び出しで実行する
- 互いに依存しない複数のコマンドを、同じブロック内の別々の Bash 呼び出しに分けて書く
```
