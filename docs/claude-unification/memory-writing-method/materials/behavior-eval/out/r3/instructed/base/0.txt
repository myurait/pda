```markdown
Bash を呼ぶときは、1 回の呼び出しに 1 つのコマンドだけを書く。`&&`、`;`、パイプ(`|`)でコマンドをつながない。

**Why:** ユーザーから明示的に指示された。連結したコマンドは内容を確認しづらく、1 つずつ実行して結果を見たいのだと考えられる。

**How to apply:** 複数のコマンドが必要なときは、Bash を複数回に分けて呼ぶ。互いに依存しない呼び出しは同じ function_calls ブロックにまとめて並列で実行する。前の結果に依存する場合は、結果を待ってから次を呼ぶ。
```
