```markdown
- Bash の 1 回の呼び出しの command に、コマンドを 1 つだけ書く
- Bash の command に、&&・||・;・パイプ (|) でつないだ複数のコマンドを書かない

- 前のコマンドの結果に依存するコマンドを、前の呼び出しの結果を受け取ってから次の Bash 呼び出しで書く
```
