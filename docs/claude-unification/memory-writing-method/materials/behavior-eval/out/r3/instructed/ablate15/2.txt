Bash の呼び出しルールをメモリにまとめました。このセッションではツールが使えないため、ファイルは書き込めていません。内容をテキストで出します。Sonnet での有り無し比較の試験も実行できていません。

## 1. メモリ本体

パス: `~/.claude/memory/bash-one-command-per-call.md`

```markdown
---
name: bash-one-command-per-call
description: Bash ツールの 1 回の呼び出しには、コマンドを 1 つだけ書き、&& ・ ; ・パイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash ツールの 1 回の呼び出しの command 欄に、コマンドを 1 つだけ書く
- command 欄の中で、複数のコマンドを &&・||・;・パイプ (|) でつながない
- 互いに依存しない複数のコマンドを、同じ応答内の別々の Bash 呼び出しに分ける
- 前のコマンドの結果に依存するコマンドを、前の呼び出しの結果を受け取ってから次の Bash 呼び出しに書く

**Why:** ユーザーが明示的に指示した。つないだコマンドは 1 つの許可判断にまとまり、ユーザーが個々のコマンドを確認しづらくなる。
**How to apply:** ビルド・テスト・確認など複数の手順を含む依頼でも、手順ごとに Bash を呼ぶ。ファイルに書く内容 (シェルスクリプトなど) の中の `&&` は、この規則の対象外。
```

## 働く場面
- 「依存パッケージを入れて、ビルドして、テストを走らせて」(無いときの挙動: `npm install && npm run build && npm test` を 1 回で呼ぶ)
