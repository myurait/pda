```markdown
Bash を呼ぶときは、1 回の呼び出しに 1 つのコマンドだけを書く。`&&`、`;`、パイプ(`|`)でコマンドをつなげない。

**Why:** ユーザーから明示的に指示された。連結したコマンドは内容を把握しにくく、確認や許可の判断がしづらいため、と考えられる。

**How to apply:** 複数の処理が必要なときは、Bash 呼び出しを分ける。互いに依存しない呼び出しは同じブロックで並列に実行し、依存するものは前の結果を待ってから次を呼ぶ。
```
