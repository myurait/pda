```markdown
- Bash の 1 回の呼び出しに、コマンドを 1 つだけ書く
- 複数のコマンドを &&・;・パイプでつなぐ書き方を使わず、コマンドごとに別の Bash 呼び出しに分ける
- 前のコマンドの出力に依存する呼び出しを、前の呼び出しの結果を受け取ってから行う

**Why:** ユーザーが明示的に指示した。メモリが無いと、エージェントは `cd dir && ls` や `git add . && git commit` のように 1 回の呼び出しへまとめる既定の挙動を取る。

**How to apply:** Bash を呼ぶすべての場面に適用する。依存関係のない複数の呼び出しは、同じブロックで並列に出してよい。
```
