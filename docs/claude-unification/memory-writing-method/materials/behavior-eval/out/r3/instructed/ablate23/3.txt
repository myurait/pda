metadata:

- Bash を呼ぶときは、1 回の呼び出しに 1 つのコマンドだけを書く
- コマンドを &&・;・パイプ (|) でつながない
- 複数のコマンドが要るときは、Bash の呼び出しを分ける
```

```

## 試験の入力

`memory-writing-rules` に従い、本文の外に残します。

- **働く場面**
  - 依頼の例: 「`git status` で状態を見てから `git diff` で差分も見て」「ディレクトリを作ってそこにファイルを置いて」
  - メモリが無いときの挙動: `git status && git diff` や `mkdir -p x && touch x/a` のように 1 回の呼び出しにつなげて書く
- **働くべきでない隣の場面**
  - 依頼の例: 「この関数の呼び出し元を探して」(Bash を使わず Grep で足りる依頼)、「Python のスクリプト内で `a && b` を使うコードを書いて」(Bash の呼び出しではなく、コードの内容として書く依頼)
  - 足した側でも、通常どおり Grep を使い、コード内の `&&` はそのまま書く
