Bash の呼び出しを 1 回に 1 コマンドにする件を、メモリとして書きました。このセッションにはツールがないので、ファイルは作らず内容だけを出力します。保存するときは下のパスに置いてください。

## `~/.claude/memory/bash-single-command-per-call.md`

```markdown
---
name: bash-single-command-per-call
description: Bash を呼ぶとき 1 回の呼び出しに 1 つのコマンドだけを書き、&& ; | でつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash を呼ぶとき、1 回の呼び出しに 1 つのコマンドだけを書く
- `&&`・`;`・パイプ `|` でコマンドをつながない
- 続けて実行したいコマンドを、別々の Bash 呼び出しに分ける
```

## `~/.claude/MEMORY.md` に追記する行

```markdown

```

`memory-writing-rules` は Sonnet での有り無しの比較を求めていますが、ツールがないので実施していません。試験の入力として、次の場面を残します。

- **働く場面**
  - 「git status を見てから git diff も見せて」
  - 「ファイル一覧を grep で絞って件数も数えて」
  - メモリが無いときは `git status && git diff` のように 1 回でつなぐ挙動になります。
- **働くべきでない隣の場面**
  - 「README を要約して」のようにコマンドが 1 つで済む依頼
  - 依頼文にあるコマンドの解説だけを求める依頼
  - どちらでも、足した側と足さない側で挙動が変わらないことを確かめます。

ツールを使えるセッションで、この入力を使って 5 回ずつ比較してください。
