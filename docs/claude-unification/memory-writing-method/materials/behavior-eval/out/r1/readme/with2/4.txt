## インストール

### 前提条件

- macOS
- [Homebrew](https://brew.sh/)

### Homebrew でインストールする

社内 tap `canly/tap` を追加してから、`canly-sync` をインストールします。

```sh
brew tap canly/tap
brew install canly-sync
```

tap の追加とインストールは、次のように 1 コマンドでも実行できます。

```sh
brew install canly/tap/canly-sync
```

### インストールの確認

```sh
canly-sync --version
```

バージョンが表示されれば完了です。

### アップデート

```sh
brew update
brew upgrade canly-sync
```

### アンインストール

```sh
brew uninstall canly-sync
brew untap canly/tap
```

### トラブルシューティング

- `brew tap` が失敗する場合は、`canly/tap` リポジトリへのアクセス権限があるか確認してください。社内のプライベートリポジトリであれば、GitHub の認証設定が必要です。
- `canly-sync: command not found` と表示される場合は、`brew doctor` を実行し、Homebrew の `bin` ディレクトリが `PATH` に含まれているか確認してください。
```
