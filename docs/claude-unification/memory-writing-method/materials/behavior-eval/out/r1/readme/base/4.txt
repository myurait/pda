## インストール

`canly-sync` は社内の Homebrew tap `canly/tap` から配布しています。

### 前提条件

- macOS
- [Homebrew](https://brew.sh/) がインストール済みであること
- 社内の tap にアクセスできる権限(GitHub の組織アカウントでの認証など)

### インストール手順

1. tap を追加します。

   ```sh
   brew tap canly/tap
   ```

2. `canly-sync` をインストールします。

   ```sh
   brew install canly/tap/canly-sync
   ```

   tap 追加済みであれば、次のように短く書くこともできます。

   ```sh
   brew install canly-sync
   ```

3. インストールを確認します。

   ```sh
   canly-sync --version
   ```

### アップデート

```sh
brew update
brew upgrade canly-sync
```

### アンインストール

```sh
brew uninstall canly-sync
brew untap canly/tap   # tap も不要な場合
```

### トラブルシューティング

- **`brew tap` で認証エラーになる場合**: tap のリポジトリへのアクセス権限と、GitHub の認証設定(SSH キーや `gh auth login`)を確認してください。
- **`command not found: canly-sync` と表示される場合**: シェルを再起動するか、`brew --prefix`/bin が `PATH` に含まれているか確認してください。
- 解決しない場合は、社内の担当チームに連絡してください。
```
