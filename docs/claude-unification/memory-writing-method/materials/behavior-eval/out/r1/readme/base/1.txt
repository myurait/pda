## インストール

`canly-sync` は社内の Homebrew tap(`canly/tap`)から配布しています。

### 前提条件

- macOS(Homebrew が導入済みであること)
- 社内リポジトリへのアクセス権限

Homebrew が未導入の場合は、先に [Homebrew 公式サイト](https://brew.sh/) の手順でインストールしてください。

### インストール手順

1. tap を追加します。

   ```sh
   brew tap canly/tap
   ```

2. `canly-sync` をインストールします。

   ```sh
   brew install canly/tap/canly-sync
   ```

3. インストールを確認します。

   ```sh
   canly-sync --version
   ```

### アップデート

```sh
brew update
brew upgrade canly-sync
```

### アンインストール

```sh
brew uninstall canly-sync
brew untap canly/tap   # tap も不要な場合
```

### トラブルシューティング

- **`brew tap` で認証エラーが出る場合**: 社内リポジトリへのアクセス権限と、Git の認証設定(SSH キーまたはトークン)を確認してください。
- **`command not found: canly-sync` と表示される場合**: `brew --prefix`/bin が `PATH` に含まれているか確認し、シェルを再起動してください。
```
