## インストール

`canly-sync` は Homebrew の tap `canly/tap` から配布しています。

### 前提条件

- macOS
- [Homebrew](https://brew.sh/) がインストール済みであること
- `canly/tap` にアクセスできる GitHub 権限があること(社内向けのため)

### インストール手順

1. tap を追加します。

   ```sh
   brew tap canly/tap
   ```

2. `canly-sync` をインストールします。

   ```sh
   brew install canly/tap/canly-sync
   ```

3. インストールを確認します。

   ```sh
   canly-sync --version
   ```

### アップデート

```sh
brew update
brew upgrade canly-sync
```

### アンインストール

```sh
brew uninstall canly-sync
brew untap canly/tap
```

### トラブルシューティング

- **tap を追加できない**: GitHub の認証と、`canly` organization へのアクセス権限を確認してください。
- **`canly-sync: command not found`**: 新しいシェルを開くか、`brew doctor` で `PATH` の設定を確認してください。
```
