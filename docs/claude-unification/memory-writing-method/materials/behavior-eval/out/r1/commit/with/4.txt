```
fix: 決済 API のタイムアウトを 30 秒から 10 秒に短縮

決済 API 呼び出しのタイムアウト値を 30 秒から 10 秒に変更する。

理由:
- <変更の理由を書く。例: 応答待ちでリクエストが長時間滞留するのを防ぐ>

影響:
- 決済 API の応答が 10 秒を超えた場合、従来より早くタイムアウトエラーになる
```

- 件名の種別は、挙動の調整なので `fix:` にしました。設定値の変更として扱うなら `chore:` や `config:` が合います。
- 理由が分かれば、仮置きの行を差し替えます。
- 本文の「影響」は、タイムアウト後の再試行や二重決済の扱いに触れる内容にもできます。
- プロジェクトのコミット規約が Conventional Commits でない場合は、件名の接頭辞を外します。
