## 試験の入力

このセッションにはツールがなく、Sonnet での有り無し比較は実行していません。比較に使う入力は次のとおりです。

- **働く場面:** 「決済 API のタイムアウトが増えた原因を調べて」のように、原因を問う依頼です。
  - メモリが無いときの挙動は、「v2.3 のリリースが原因」のように時点を原因として答えることです。
- **働くべきでない隣の場面:** 「タイムアウトが増え始めたのはいつ?」のように、時点を問う依頼です。
  - この場合は、日時やリリースを答えて構いません。

試験は上の入力で、メモリを足した側と足さない側を5回ずつ比べて行う必要があります。
