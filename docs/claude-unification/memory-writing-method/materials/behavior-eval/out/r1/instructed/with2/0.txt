Bash の呼び出しを 1 回につき 1 コマンドにするメモリを書きました。このセッションにはファイルを書くツールがないので、各ファイルのパスと全文を下に出します。Sonnet での有り無しの比較試験も実行できていません。試験の入力だけ別ファイルとして残しました。

## 1. メモリ本体

パス: `~/.claude/memory/bash-one-command-per-call.md`

```markdown
---
name: bash-one-command-per-call
description: Bash ツールの 1 回の呼び出しに書くコマンドを 1 つだけにし、&& や ; やパイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash ツールの 1 回の呼び出しに、コマンドを 1 つだけ書く
- 複数のコマンドを実行するとき、コマンドごとに別の Bash 呼び出しにする
- Bash の command に、`&&`・`;`・`|` でコマンドをつなぐ書き方を使わない
```

# 働く場面 (メモリが無いときの挙動)
