```markdown
metadata:

- Bash の 1 回の呼び出しに、コマンドを 1 つだけ書く
- &&・;・パイプでコマンドをつながず、コマンドごとに Bash の呼び出しを分ける
- 互いに依存しない Bash の呼び出しを、同じ関数呼び出しブロックにまとめて並列で実行する
- 前のコマンドの出力が次のコマンドの入力になるとき、前の呼び出しの結果を受け取ってから次の呼び出しを行う
```
