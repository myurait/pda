```markdown
Bash を呼ぶときは、1 回の呼び出しに 1 つのコマンドだけを書く。`&&` や `;` やパイプ (`|`) でコマンドをつなげない。

**Why:** ユーザーから明示的に指示された。連結したコマンドは、何を実行するのかをユーザーが確認しにくくなるためと考えられる。

**How to apply:** 複数の処理が必要なときは、Bash 呼び出しを分ける。互いに依存しない呼び出しは、同じブロックで並列に呼ぶ。前の結果に依存する呼び出しは、結果を待ってから呼ぶ。
```
