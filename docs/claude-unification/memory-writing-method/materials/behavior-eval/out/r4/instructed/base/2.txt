```markdown
name: bash-single-command
description: Bash ツールは 1 回の呼び出しにつき 1 コマンドだけ。&&・;・パイプで連結しない
metadata:
  node_type: memory
  type: feedback
---

Bash ツールを呼ぶときは、1 回の呼び出しに 1 つのコマンドだけを書く。`&&`、`;`、パイプ(`|`)でコマンドをつながない。

**Why:** ユーザーから明示的に指示された。連結されたコマンドは内容を確認しにくく、意図しない動作を避けたいためと考えられる。

**How to apply:** 複数の処理が必要なときは、Bash を複数回に分けて呼ぶ。互いに依存しない呼び出しは、同じブロックで並列に呼んでよい。前の結果に依存する場合は、結果を待ってから次を呼ぶ。
```

**ファイル2: `~/.claude/MEMORY.md`**(インデックスに次の1行を追記)

```markdown
- [Bash は 1 呼び出し 1 コマンド](memory/bash-single-command.md) — &&・;・パイプで連結せず、1 回に 1 コマンドだけ書く
```

今後 Bash を使うときは、この指示に従って 1 回の呼び出しに 1 コマンドだけを書きます。
