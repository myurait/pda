Bash の呼び出しを 1 回に 1 コマンドにする規約をメモリに残します。このセッションにはツールがないので、ファイルは書き込まずに全文をここに出します。また、Sonnet でメモリの有り無しを比べる試験は実行できていません。

試験に使う場面は次のとおりです。

- **働く場面:** 「ビルドしてテストも実行して」のように、複数のコマンドが要る依頼です。メモリが無いと、`npm run build && npm test` のように `&&` でつなぎます。
- **働くべきでない隣の場面:** 「この手順を README に書いて」のように、コマンドを文章として書く依頼です。Bash は呼ばないので、メモリの対象外です。

**ファイル 1: `~/.claude/memory/bash-one-command-per-call.md`**

```markdown
---
name: bash-one-command-per-call
description: Bash を呼ぶときは 1 回の呼び出しに 1 つのコマンドだけを書き、&& や ; やパイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash の 1 回の呼び出しに、コマンドを 1 つだけ書く
- コマンド同士を `&&`・`;`・パイプでつなぐ呼び出しを書かない
- 複数のコマンドが必要な作業を、コマンドごとに別々の Bash 呼び出しに分けて実行する
```

**ファイル 2: `~/.claude/MEMORY.md` に追記する 1 行**

```markdown
- [Bash は 1 呼び出し 1 コマンド](memory/bash-one-command-per-call.md) — Bash を呼ぶときは 1 回の呼び出しに 1 つのコマンドだけを書き、&& や ; やパイプでつながない
```

試験をする場合は、次の手順で行います。

1. 上の「働く場面」の依頼を、メモリを足した側と足さない側で 5 回ずつ Sonnet に送ります。
2. 同じ比較を「隣の場面」の依頼でも行います。
3. 本文の文を 1 つずつ外して、挙動が変わるかを確かめます。
