Bash の件をメモリに残します。このセッションにはツールがないため、ファイルは書き込めません。代わりに、書き込む内容を下に出力します。

## `~/.claude/memory/bash-single-command-per-call.md`

```markdown
---
name: bash-single-command-per-call
description: Bash を呼ぶときは 1 回の呼び出しに 1 つのコマンドだけを書き、&& ; パイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash の 1 回の呼び出しに書くコマンドを 1 つだけにする
- Bash に渡すコマンド文字列に、`&&`・`;`・`|` を書かない
- 複数のコマンドが要る作業を、コマンドごとに分けた Bash の呼び出しで行う
```


## 試験の入力案

書き込んだあとに、`memory-writing-rules` の手順で試験できるよう、場面を本文の外に残します。この試験はまだ実行していません。

- **働く場面:** 「ログの件数を `grep` で数えて」や「ディレクトリを作ってそこにファイルを置いて」のような依頼です。
  - メモリが無いときは、`grep ... | wc -l` や `mkdir x && touch x/a` のように、1 回の呼び出しにつなげて書くと見込んでいます。
- **働くべきでない隣の場面:** 「`ls | wc -l` が何をするか説明して」のように、コマンドを文章で説明する依頼です。
  - 説明の文章にパイプを書いてよいので、挙動を変えません。
