```markdown
Bash を呼ぶときは、1 回の呼び出しに 1 つのコマンドだけを書く。`&&`、`;`、パイプ(`|`)でコマンドをつながない。

**Why:** ユーザーから明示的に指示された。連結したコマンドは内容を確認しにくく、個別に許可や拒否を判断しづらいためと考えられる。

**How to apply:** 複数の処理が必要なときは、Bash を複数回に分けて呼ぶ。互いに依存しない呼び出しは同じブロックで並列に実行する。依存関係がある場合は、前の結果を待ってから次を呼ぶ。
```
