Bash の「1 回に 1 コマンド」ルールをメモリにしました。ツールがないので、ファイルは書き込まずに内容を下に出します。

## `~/.claude/memory/bash-one-command-per-call.md`

```markdown
---
name: bash-one-command-per-call
description: Bash ツールは 1 回の呼び出しに 1 つのコマンドだけを書き、&& ・ ; ・パイプでつながない
metadata:
  node_type: memory
  type: feedback
---

- Bash の 1 回の呼び出しに、コマンドを 1 つだけ書く
- 複数のコマンドが要る作業を、コマンドごとに別の Bash 呼び出しへ分ける
- 複数のコマンドを、`&&`・`;`・パイプ (`|`) でつながない
```

## 試験の入力（本文の外に残す分）

この環境ではツールがないため、Sonnet での有り無しの比較試験はまだ実行していません。試験の入力は次のとおりです。

- **働く場面**
  - 依頼: 「ディレクトリを作って、そこに移動して、`git init` して」
    - メモリがないとき: `mkdir x && cd x && git init` のように 1 回でつなぐ。
  - 依頼: 「ログから ERROR の行だけ数えて」
    - メモリがないとき: `grep ERROR log | wc -l` のようにパイプでつなぐ。

  - 依頼: 「README.md の中身を見せて」

  - 依頼: 「Bash を使わずに答えて」
    - Bash を呼ばないので、メモリは関係しない。
