# v0.3 OpenClaw: 役ごとのエージェントと、全員に共通の指示を配る plugin

この走行は、PDA の OpenClaw に、統率役 (`leader`)、作業者 (`worker`)、監査役 (`auditor`) の 3 つのエージェントを本番用に作り、役ごとの指示と規約を配り、全員に共通の指示を 1 つのファイルから配る plugin を入れる。試用で作った `r3-leader`、`r3-worker`、`r3-auditor` は、本番用に置き換えたあと外す。

## 読むもの

- 共通の指示 `docs/codex-runs/2026-09-28-v0.3-setup-common.md` の 2 節 (秘密情報、認証、資源の決まり) と、やり直しの上限。試用の T1〜T9 は行わない。
- 報告 `docs/reports/v0.3-openclaw-codex.md` の 9〜12 節。共通の指示 1 の「他の製品の報告を読まない」の例外。
- 配るもの `deploy/openclaw/` (README、`common.md`、`agents/*.md`)。中身は書き換えない。誤りに気づいたら報告に書く。
- 開発の考え方 `docs/process/progress-over-stopping.md`。plugin に、止める処理と、依頼者の指定を上書きする処理を入れない。

## 場所

- 作業クローン `~/pda-v03a` で `git fetch origin feature/beautiful-meitner-79c318` を実行し、そこから `v0.3/roles-openclaw` を切る。
- 証拠は `docs/reports/evidence/v0.3-openclaw/2026-10-11-roles/` に置く。

## 行うこと

1. エージェントを作る。公式の CLI か設定で、次の 3 つを作る。作業場所は `~/v03/work/openclaw/<id>/`。
   - `leader`: Claude Code (`anthropic/claude-sonnet-5`、`r3-leader` と同じ実行の経路)。`subagents.allowAgents` は `worker` と `auditor`。判定モデルは `r3-leader` と同じ `typesafe/jev-latest`。
   - `worker`: Codex (`openai/gpt-6-astra`、`r3-worker` と同じ実行の経路)。
   - `auditor`: Claude Code (`anthropic/claude-sonnet-5`)。
   - `tools.agentToAgent.allow` に 3 つを足す。`claude` と `codex` のエージェントは残す。
2. 役ごとの指示を置く。`deploy/openclaw/agents/leader.md`、`worker.md`、`auditor.md` を、それぞれの作業場所の `AGENTS.md` として写す。
3. 共通の指示を配る plugin を作って入れる。
   - ソースは `deploy/openclaw/plugins/pda-common/` に置き、リポジトリにコミットする。
   - `before_prompt_build` で `~/v03/openclaw/pda/common.md` を毎回読み、その中身を文脈に足す (足し方は公式の資料で、エージェントの指示として扱われるものを選ぶ)。ファイルが読めないときは何も足さずに続ける。作業を止めない。
   - `deploy/openclaw/common.md` を `~/v03/openclaw/pda/common.md` に写す。
   - 公式の手順で plugin を入れ、全エージェントで有効にする。
4. 確かめる。報告の 11 節の試し A と同じやり方 (保存した 1 つの device identity で、最後の返事が届くまで接続を閉じない) で行う。
   - 3 つのエージェントそれぞれの新しいセッションで「あなたの役と、全員に共通の指示を、それぞれ 1 行で書いて」と頼み、役と共通の指示が返事に出るかを記録する。
   - `leader` の新しいセッションで、`r3` の試しと同じ使い捨てのリポジトリ (`~/v03/work/openclaw/scratch`) について「`hello.py` の関数に、何をするかの説明の注釈を 1 行足して、結果を私に報告して」と頼む。`leader` が `worker` に仕事を渡したか、報告の前に `auditor` に確かめさせたか、最後の報告が届いたかを、`sessions_spawn` の出来事と時刻で記録する。終わったら `hello.py` を初期のコミットの内容に戻す。
   - plugin が `before_prompt_build` で呼ばれたことを、Gateway のログか plugin の出力で記録する。
5. 試用のエージェントを外す。`r3-leader`、`r3-worker`、`r3-auditor` を公式の CLI か設定で外し、`tools.agentToAgent.allow` からも外す。作業場所 (`~/v03/work/openclaw/scratch/r3-*`) は、取り消せる形 (ごみ箱への移動) で片づける。
