## Claude の動かし方の決まり

- 公式文書 [Claude unified terminal](https://docs.happier.dev/sessions/claude-unified-terminal) の経路で動かす。"Run Claude Code once, in a real terminal that Happier and you both drive, instead of running a separate Agent SDK process behind the app."
- サーバの機能フラグで開ける機能である。自前のサーバ (`~/v03/happier/compose.yaml` の relay) で、文書とソースからこのフラグの開け方を探して開ける。文書の手がかりは、Settings → AI backends → Claude Code の「Use unified terminal runtime」と、フラグ名 `providers.claude.unifiedTerminal`、`providers.claude.unifiedTerminal.tuiRuntimeControl`。参照用のソースは `~/v03/happier/source/` にある。
- Claude Code を動かす端末 (Terminal host) は、happier に同梱の zellij を選ぶ。既定の「Auto」は、このマシンに tmux があるので tmux を使う。tmux を使わない。
- 開けられなければ、試した設定と画面やログの文言を記録し、T2、T3 を未実施とする。
