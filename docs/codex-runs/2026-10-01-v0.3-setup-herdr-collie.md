# v0.3 候補のセットアップ: herdr-collie

共通の指示 `docs/codex-runs/2026-09-28-v0.3-setup-common.md` を最初に読み、それに従う。この製品について決まっていることは次のとおり。

- 製品: https://github.com/herdrdev/herdr と https://github.com/AltanS/collie
- 公式文書: https://herdr.dev/docs/
- 名前 (ブランチ、ディレクトリ、unit、報告書、証拠に使う `<製品>`): `herdr-collie`
- ブランチ: `v0.3/setup-herdr-collie`
- 待ち受けのポート: 5117
- Tailscale Serve の番号 (報告書の「人の手順」に書くもの): 19117
- 資料から分かっている導入の手がかり: herdr は端末の多重化のサーバ ("a server running in the background"、"Each machine keeps its own Herdr server")。collie は "A mobile web interface for terminal-based AI agents, served over Tailscale" で、既定の接続先は herdr (collie の README)。herdr のペインで claude と codex を起こし、collie の画面から操作する。待ち受けのポートは collie の画面に使う。tmux と zellij は使わない。

手がかりは資料の記述で、確かめたものではない。食い違ったら製品の実際の振る舞いを記録する。
