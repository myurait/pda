- 製品: https://github.com/stablyai/orca
- 公式文書: https://www.onorca.dev/docs
- 名前 (ブランチ、ディレクトリ、unit、報告書、証拠に使う `<製品>`): `orca`
- ブランチ: `v0.3/setup-orca`

- Tailscale Serve の番号 (報告書の「人の手順」に書くもの): 19113
- 資料から分かっている導入の手がかり: "Use orca serve when the host should run without the desktop window" (`docs/reference/headless-linux-server.md`)。iOS と Android の app がある。
