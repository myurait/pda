# v0.3 候補のセットアップ: happier

共通の指示 `docs/codex-runs/2026-09-28-v0.3-setup-common.md` を最初に読み、それに従う。この製品について決まっていることは次のとおり。

- 製品: https://github.com/happier-dev/happier
- 公式文書: https://docs.happier.dev/
- 名前 (ブランチ、ディレクトリ、unit、報告書、証拠に使う `<製品>`): `happier`
- ブランチ: `v0.3/setup-happier`
- 待ち受けのポート: 5112
- Tailscale Serve の番号 (報告書の「人の手順」に書くもの): 19112
- 資料から分かっている導入の手がかり: デーモンがエージェントのプロセスを起こし、中継サーバを自前で 1 コマンドで立てられ、Docker もあると書かれている。Web は cloud.happier.dev だが、中継サーバを自前で立て、Web の画面もこのマシンから配る形を探して使う。
- Claude の動かし方の決まり: Claude は、Claude Code の実行ファイルをそのまま動かす local の経路で動かす (`apps/cli/src/backends/claude/loop.ts` の既定)。Agent SDK を使う remote の経路 (`apps/cli/src/backends/claude/remote/claudeRemoteAgentSdk.ts`) に切り替えない。画面や API から入力したときに local のままか remote へ切り替わったかを、ログか T6 の親プロセスで確かめて記録する。

手がかりは資料の記述で、確かめたものではない。食い違ったら製品の実際の振る舞いを記録する。
