# v0.3 候補のセットアップ: codexia

共通の指示 `docs/codex-runs/2026-09-28-v0.3-setup-common.md` を最初に読み、それに従う。この製品について決まっていることは次のとおり。

- 製品: https://github.com/milisp/codexia
- 公式文書: https://github.com/milisp/codexia
- 名前 (ブランチ、ディレクトリ、unit、報告書、証拠に使う `<製品>`): `codexia`
- ブランチ: `v0.3/setup-codexia`
- 待ち受けのポート: 5120
- Tailscale Serve の番号 (報告書の「人の手順」に書くもの): 19120
- 資料から分かっている導入の手がかり: "Headless backend: Axum web server for remote control"、"remote control via headless web server (including iOS)" (README)。
- Claude の動かし方の決まり: Claude は Rust の crate (claude-agent-sdk-rs) が claude の実行ファイルを動かす経路で動かす。ACP の経路 (claude-code-acp) は使わない。T6 で、claude の実行ファイルがどの引数で起こされたかを記録する。

手がかりは資料の記述で、確かめたものではない。食い違ったら製品の実際の振る舞いを記録する。
