# 運用文書

`docs/operations/` 配下の運用文書と、その用途を示します。

- [`pda-improvement-cycle.md`](pda-improvement-cycle.md) — PDA改善タスクの自動捕捉、日次振り返り、隔離実装、および承認後の最終反映手順を定めます。
- [`worktree-lifecycle.md`](worktree-lifecycle.md) — PDA作業worktreeの生成、保持、削除、監査に関するライフサイクル方針を定めます。
- [`local-continuity-backup.md`](local-continuity-backup.md) — PDA継続状態の同一ホスト内バックアップについて、対象、導入、検証、復元手順と制約を説明します。
- [`adversarial-suite.md`](adversarial-suite.md) — 自律改善の統制を迂回する試みが機械的に遮断されることを継続検証するテスト台帳と実行方法を示します。
