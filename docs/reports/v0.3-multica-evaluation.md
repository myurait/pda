## 結論

T1〜T5 と T9 は通った。必須の条件のうち、R1、R2、R7、R13 をミニ PC の上で確かめた。R4 は常駐と画面のログインまでを確かめ、PC とスマホからの到達はオーナーのプレビューで確かめる。

- 構成は、公式の Docker Compose (PostgreSQL、backend、frontend) に nginx を足して `127.0.0.1:5101` にまとめ、daemon を同じ user unit から起こした。画面には、multica 自身のアカウントでメールの確認コードを使ってログインする。
