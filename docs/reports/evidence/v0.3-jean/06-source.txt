1: //! Codex app-server manager
2: //!
3: //! Manages a `codex app-server` process that communicates via JSON-RPC 2.0.
4: //!
5: //! On Unix the server is spawned **detached** (nohup + own process group) and
6: //! listens on a Unix domain socket (`--listen unix://<path>`, WebSocket
7: //! framing). Jean connects as a WebSocket client. Because the server is not a
8: //! child of Jean and holds no pipes to it, in-flight turns survive Jean
9: //! quitting; on restart Jean reconnects to the live server and re-subscribes
10: //! to threads via `thread/resume`.
11: //!
12: //! On Windows (and with `JEAN_CODEX_STDIO=1` on Unix) the legacy transport is
13: //! used: a piped child process speaking newline-delimited JSON over stdio,
14: //! killed when Jean exits.
