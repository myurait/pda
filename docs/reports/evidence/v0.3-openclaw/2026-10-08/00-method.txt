採取:
- 前回の product ディレクトリ内の client.mjs / trial.mjs を今回専用の補助スクリプトへ複製。製品コードは編集していない。
- node 24 標準 WebSocket で ws://127.0.0.1:5114/ へ接続。protocol 4。クライアント用 Ed25519 identity はメモリ内のみ。
- chat.send / sessions.messages.subscribe / chat.abort が製品への操作。受信時刻 UTC と performance.now による経過秒を JSON Lines に保存。
- JSON フィールドの token / password / secret / signature / nonce 等と既知の秘密形式は保存前に伏せる。
- T2/T4 は説明・ツール開始/結果・最終応答、git diff を採取。T3/T5 は同じ依頼・同じセッションを再利用。
- 停止のトリガーは最初の説明文増分、またはツールの途中イベント。ps 採取後に chat.abort を送り、その直前から aborted イベント受信までを計測。
- 終了約2秒後に chat.history / sessions.list とプロセスを再確認。Codex の app-server は run の停止後も共有される。
- T6 は T2/T4 実行中の ps -ww -eo pid,ppid,etime,args --forest から Gateway と子孫を抽出。cwd も保存。RSS の採取は除去した。
- T2/T3 間・後と終了時に journal と当日の構造化 Gateway ログを検索。範囲は起動前から各採取時点まで。T2開始以降の記録欠落キーワードは別に0件を確認。
- 起動直後に前回セッション由来の empty_response/fallback があったため、時刻・sessionKey・理由を記録して区別した。
- T1〜T5 は各1回。依頼の再送によるやり直しなし。npm install は1回。Doctor の診断後、案内された --fix を1回実行。
- T7/T8/T9 は実行していない。ログに出る前回の handoff セッションと製品自身の状態出力は今回の試用ではない。

清掃:
- systemctl --user stop、MainPID=0、待ち受けなし、対象子 PID の消滅を確認。
- 今回の CLI backup 2個と OpenClaw の設定 backup を内容を開かず削除。scratchを初期化し __pycache__ を削除。
- /tmp の今回の MCP 設定は製品終了時に消滅。既存の他製品の backup と実行ファイル・製品 state/logs は残す。
- 秘密ファイルの内容は検査しない。ファイル名と ls -l によるメタデータで複製候補を確認。前後の CLI mcp list を比較。
