118: ### Permissions and scope
119:
120: Hook registration does not bypass plugin loading rules. The plugin must be
121: loaded and enabled; `plugins.enabled`, `plugins.allow`, and `plugins.deny` still
122: apply. Run `openclaw plugins reload <id>` after changing plugin code. With the default hybrid
123: reload mode, hook policy changes hot-reload the existing plugin runtime.
124:
125: - Non-bundled plugins need explicit
126:   `plugins.entries.<id>.hooks.allowConversationAccess: true` for
127:   `before_model_resolve`, `agent_turn_prepare`, `before_prompt_build`,
128:   `before_agent_reply`, `llm_input`, `llm_output`, `before_agent_finalize`,
129:   `agent_end`, and `before_agent_run`. Bundled plugins are allowed unless this
130:   option is explicitly `false`.
131: - `session_end` remains available as a metadata-only lifecycle hook without
132:   that grant. Its bounded `ctx.endedTranscript` reader is available only when
133:   the effective conversation-access policy allows it; see the
134:   [session lifecycle contract](/plugins/hooks/reference#sessions-and-compaction).
135: - `allowPromptInjection: false` blocks `agent_turn_prepare`,
136:   `before_prompt_build`, `heartbeat_prompt_contribution`, and durable next-turn
137:   injections. It defaults to allowed, but does not grant conversation access.
138:   The first two hooks therefore need both permissions.
139: - These are specific registration gates, not a sandbox or a universal filter
140:   for every hook that can see message data. Install only plugins you trust.
141:
142: Incognito sessions do not dispatch `llm_input` or `llm_output` observations.
143: Their `agent_end` hooks still receive run identity, success, and duration for
144: cleanup and settlement, but receive empty `messages` and no `error` text.
