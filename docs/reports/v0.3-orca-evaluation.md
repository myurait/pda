## 指示から外れたこと

- Orca が、初めて起動したときに Codex の認証を自分の場所へ写した。写したファイルは `~/v03/agent-home/.config/orca/codex-runtime-home/` の `home/auth.json`、`system-default-auth.json`、`shared-runtime-auth-provenance.json` の 3 つ。Claude の認証は写していない。
  - 原因は設計側の指示にある。共通の指示どおり unit に `CODEX_HOME=/home/user/pda/secrets/codex` を渡したため、Orca は HOME の `.codex` とは別の場所を指していると判定し、標準の外の home として扱った (`src/main/codex/codex-real-home-path.ts` の 22〜36 行目)。
  - Codex は、内部の環境変数 `ORCA_CODEX_HOME` を同じ値で足して再起動し、以後の試用では HOME の `.codex` を通して元の認証を使わせた。公式の手順ではない。
  - 写された 3 つのファイルは、2026-10-01 にオーナーが消した。
- Orca の hook は試用の終わりに `agent hooks off` で外し、Orca の状態の表示では両方とも入っていない。信頼の印は残っている (2026-10-01 オーナー承認の範囲)。
