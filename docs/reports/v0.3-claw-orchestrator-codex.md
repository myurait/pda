## 6. 人の手順

root 権限が必要になった手順はなかった。試用終了時は停止しているため、画面を開く際は利用者 `user` で起動する。

```sh
systemctl --user start v03-claw-orchestrator.service
/home/user/.local/bin/tailscale-pda serve --bg --https=19123 http://127.0.0.1:5123
```

開く URL は `https://<このミニPCのTailscaleホスト名>:19123/dash`。現在の unit は HTTP 認証を無効にする設定なので、画面ログイン手順はない。Tailscale Serve の上記コマンドはこの走行では実行していない。ローカルで開く場合は `http://127.0.0.1:5123/dash`。

再起動後の自動起動はこの走行で有効化していない。必要な場合のコマンドは `systemctl --user enable v03-claw-orchestrator.service`。閲覧終了後の停止は次のとおり。

```sh
systemctl --user stop v03-claw-orchestrator.service
```
