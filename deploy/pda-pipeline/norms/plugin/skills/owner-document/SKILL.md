# owner-document

オーナーに見せる資料は、それ1つで読める自己完結のHTMLにし、道具 `attach_document` で返事に付ける。返事の本文には、結論と、資料の題名と、資料で何が分かるかだけを書く。

## 書く前に決めること

- だれが、だれに、何のために見せる資料かを1行で書く。
  - オーナーに判断を求める資料: 選択肢・推奨・回答の欄を付ける。
  - オーナーがほかの人に見せる資料、オーナー自身の整理のための資料: 選択肢・推奨・回答の欄を付けない。
- 題名と見出しには、オーナーが依頼で使った語をそのまま使う。

## 判断を求める資料の形

- 1つの項目で1つの判断だけを求める。
- 項目の中は、上から次の順に1列で置く。
  1. 決めること (問いの形)
  2. 今の状態
  3. 判断に要る事実
  4. 選択肢と、選んだ場合に起きること
  5. 推奨と、その根拠の事実
  6. 選ぶ欄と、自由回答の欄
- 選ぶ欄はチェックボックスにし、最初から印を付けない。推奨は、選択肢の名前の横に「(推奨)」と書く。
- 選んだ結果をそのまま貼れる回答の欄と、写すボタンを付ける。
- 見た目で違う選択肢は、同じ画面・同じ位置の絵を並べる。
- 構成 (層、流れ、部品のつながり) を確かめてもらう資料は、図を先頭に置く。
- 資料の文は常体 (だ・である調) で書く。

## HTMLの決まり

- `<style>` と `<script>` はインラインで書く。外のファイルを参照しない。
- スマホの幅で横にはみ出さない作りにする。
- 英字・数字と日本語の間に空白を入れない。
